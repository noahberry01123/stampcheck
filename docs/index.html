StampCheck

Find out if your human approval step still checks anything

Many systems send automated decisions, like refunds, account locks, or content takedowns, to a person for approval. Over time, reviewers learn that the software is usually right and start approving almost everything in seconds, while the log still says "human reviewed". StampCheck reads the approval logs you already have and tells you, in plain language, when a review step has stopped filtering anything.

Get started in 5 minutes →

Try it

$ pip install stampcheck
$ stampcheck demo

Works with the approval logs you already have. Adding an opened_at timestamp makes the timings exact.

The minimum is who decided, what they decided, when, and what the system recommended. Without the recommendation, only the speed checks run. Which checks can run depends on your data, and the report lists any that couldn't.

It is read-only. It never blocks or changes a decision, and nothing leaves your machine except an optional Slack alert.

Three fingerprints it looks for

  1. Agreeing with almost everything, in secondsThe reviewer almost never disagrees with the software and decides in under 30 seconds. The step adds delay and filters nothing.
  2. Drifting from careful to fastMinutes per case a month ago, seconds per case now. Averages over the whole period hide it, so StampCheck compares the last two weeks with the four before.
  3. Timeouts that end in approvalCases nobody reviewed before the deadline that went through anyway, because the timeout default fails open.

It also flags approvals executed more than once, logging that looks hard-coded, and queues too big to review properly.
